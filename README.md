# 🛍️ Myntra Clone

A responsive **Myntra Clone** website built using **HTML and CSS**.
This project recreates the basic look and feel of the Myntra fashion shopping platform, including navigation, banners, categories, offers, and product sections.

## 📸 Project Overview

The goal of this project is to practice **frontend development concepts** such as:

* HTML5 structure
* CSS styling
* Flexbox
* Responsive layouts
* Image handling
* Navigation bar design
* Product/category sections
* Organizing website assets

## ✨ Features

* 🏠 Myntra-inspired homepage
* 🧭 Navigation bar with categories
* 🖼️ Promotional banners
* 👕 Fashion category sections
* 🎁 Offers section
* 📱 Responsive design
* 🎨 Clean and simple UI
* 📂 Organized image assets

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
